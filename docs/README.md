# ROLL Deep Dive Docs

This directory contains a code-grounded learning path for the `ROLL` repository.
It is intentionally different from `docs_roll/`: `docs_roll/` is the project's published product documentation, while this `docs/` tree is a source-reading companion for engineers who want to understand how the system is built.

## Available now

- English deep dive: [`docs/en/README.md`](en/README.md)

## Planned in the same branch

- Chinese mirror under `docs/zh/`

## What you will find in the English set

- A fast orientation guide for new readers
- A source reading roadmap tied to concrete files
- A math explainer for PPO, KL control, reward shaping, and advantage estimation
- A multi-page architecture deep dive covering runtime roles, data flow, RLVR, Agentic RL, strategy backends, and communication/offload logic
