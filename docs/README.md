# ROLL Deep Dive Docs

这个目录提供一套面向源码阅读的 ROLL 深潜学习路径。
它和 `docs_roll/` 的定位不同：`docs_roll/` 是项目现有的产品/用户文档站点，而这里的 `docs/` 更像一套给工程师、研究者和系统架构师使用的“源码剖析版伴读资料”。

## Available now / 当前内容

- English deep dive: [`docs/en/README.md`](en/README.md)
- 中文深潜教程: [`docs/zh/README.md`](zh/README.md)

## What this docs tree focuses on / 本目录重点

- 面向源码的阅读入口，而不是功能营销式简介
- 用 Mermaid 图把系统架构、数据流和通信流画透
- 把 PPO / KL / GAE / reward shaping 讲成人话
- 解释 ROLL 如何把 RL 算法和大规模 GPU 运行时拼成一个完整系统
